# Licensing

W1 NFC Reader uses a split licensing policy.

## Project software

Unless a file states otherwise, project-authored source code, build scripts and other software are distributed under:

**GNU General Public License v3.0 or later (`GPL-3.0-or-later`)**

The canonical GPL v3 text is provided in [LICENSE](LICENSE) and is also bundled in the Android application for offline viewing.

## Project documentation

Unless a document states otherwise, project-authored documentation is distributed under:

**Creative Commons Attribution-ShareAlike 4.0 International (`CC-BY-SA-4.0`)**

This includes project-authored explanatory documentation in `docs/` and repository prose such as the README.

## Third-party material

Third-party software, protocol research sources, dependency artifacts, trademarks and other third-party material retain their own copyright and license terms. Nothing in this repository relicenses third-party material contrary to those terms.

The project software license was selected to provide a compatible distribution path for protectable implementation material derived from or adapted from the `LGPL-2.1-or-later` licensed `dbmaxpayne/esphome_qalcosonicnfc` project. Required attribution and upstream notices remain preserved.

See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for provenance and dependency notices.

## Contributions

Project-authored code contributions are accepted for distribution under GPL-3.0-or-later. Project-authored documentation contributions are accepted for distribution under CC-BY-SA-4.0 unless a different compatible license is explicitly agreed before contribution.

Do not submit third-party code without clearly identifying its source and license.
